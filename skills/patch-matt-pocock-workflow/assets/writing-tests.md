# 浏览器测试编写与对测试的审查

运行测试需要浏览器或其他共享依赖时，先阅读 [共享依赖约定](shared-dependencies.md)。测试命令和工具版本从当前项目配置确定。

## 编写

后续操作依赖服务端写入或异步工作完成时，需要等待该业务完成的可观察证据，再继续导航或操作。举例来说：

- `await click()` 仅表示点击动作完成；
- 固定 sleep 也不能证明业务完成。

选择能证明所需状态的响应或界面信号，确认该信号不是写入完成前的乐观更新。

## 审查

检查操作与等待条件的因果关系。纯前端操作、刻意测试请求中断等场景不加入无意义等待。若项目已有相关 lint 规则，按该规则处理必要的局部例外并说明原因；如果发现了某种错误的模式，考虑为项目添加自定义 lint 规则，来优化审查流程。
