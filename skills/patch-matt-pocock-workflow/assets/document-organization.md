# 文档分类

创建、移动或归档文档前，按用途选择位置。下表是推荐布局；setup 时根据用户批准的方案替换为项目实际路径。

| 目录 | 用途 | 示例 |
| --- | --- | --- |
| `docs/agent/` | 给 agent 阅读的行为规范、工作流程和条件读取文档 | 协作流程、任务执行约束 |
| `docs/findings/by-agents/` | Agent 产出的详细发现、分析与报告 | 调研报告、诊断记录、文档关系图 |
| `docs/findings/TLDR/` | 人类或 agent 编写的精炼结论 | 报告摘要、关键发现与行动建议 |
| `docs/maintenance/` | 项目开发维护文档及本分类机制 | dev-spec、命令说明、环境配置、文档维护说明 |

按用途而非作者归类：agent 写的维护规范仍放维护目录。报告记录某次分析结果，不能因被引用就自动成为执行规范；需持续约束工作的结论，整理到对应规范文档并链接来源。

精炼版本链接完整来源，说明适用范围或日期；来源更新时复核摘要。维护文档保留人类和 agent 可共用的事实与操作说明，agent 专用文档通过链接引用它们。

项目已有其他分类时，在此记录其用途与路径；新内容按获准规则放置，跨类别文档选择主要用途并用链接关联。
