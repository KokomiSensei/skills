# Codex Quota Aware

仅在用户显式调用时启用，持续适用于当前任务。剩余用量较低时，根据剩余任务复杂程度判断：

- 若不足以支撑大规模sub agent并行工作，则将其并行工作转为串行工作，避免并行工作快速耗尽剩余用量，导致工作在非阶段性检查点处被强制中断；
- 若不足以支撑完成全部任务，则利用剩余用量进行阶段性收尾，暂停工作并睡眠等待重置。

开始工作时、完成有实质工作量的阶段后，以及下一轮高消耗操作前，运行本技能的 `./scripts/codex-usage.sh` （将相对路径解析为本技能目录下的绝对路径）。脚本会读取 `${CODEX_HOME:-$HOME/.codex}/sessions` 中最新的有效用量快照。

查询失败或没有 5 小时窗口时，简短报告监测不可用，保留任务进度并按现有授权继续；之后在自然检查点重试，不编造剩余量或重置时间。
